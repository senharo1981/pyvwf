# PYVWF ویب سائٹ — سیٹ اپ گائیڈ

## تصاویر کہاں رکھیں
`assets/images/` فولڈر میں بالکل انہی ناموں سے تصاویر اپ لوڈ کریں:

| تصویر | فائل کا نام |
|---|---|
| تنظیم کا لوگو | `assets/images/logo.png` |
| بانی و صدر کی تصویر | `assets/images/founder.jpg` |

اگر آپ کی تصویر jpg/png کے علاوہ کسی اور فارمیٹ میں ہو تو `index.html` میں متعلقہ `<img src="...">` لائن میں فائل کا ایکسٹینشن بدل دیں۔
جب تک یہ فائلیں موجود نہ ہوں، ویب سائٹ خود بخود ایک خوبصورت placeholder دکھائے گی — کوئی ٹوٹی ہوئی تصویر نظر نہیں آئے گی۔

## GitHub Pages پر اپلوڈ کرنے کا طریقہ
1. GitHub پر نیا ریپوزٹری بنائیں (مثلاً `pyvwf-website`)۔
2. اس فولڈر کی تمام فائلیں (`index.html`, `style.css`, `script.js`, `assets/`) ریپو میں اپلوڈ کریں۔
3. Repository → Settings → Pages میں جائیں۔
4. Branch میں `main` اور فولڈر میں `/root` منتخب کر کے Save کریں۔
5. کچھ منٹ بعد ویب سائٹ `https://username.github.io/pyvwf-website/` پر لائیو ہو جائے گی۔
6. اپنا کسٹم ڈومین (`www.PYVWF.org`) لگانے کے لیے اسی Pages سیٹنگ میں Custom domain میں ڈومین درج کریں اور اپنے ڈومین رجسٹرار میں GitHub کی بتائی گئی DNS ہدایات کے مطابق ریکارڈز شامل کریں۔

## فائلوں کی فہرست
- `index.html` — مکمل ویب سائٹ کا ڈھانچہ اور مواد
- `style.css` — مکمل ڈیزائن (رنگ، فونٹ، ریسپانسو لے آؤٹ)
- `script.js` — مینو، سکرول اینیمیشن، کاؤنٹر، فارمز
- `assets/images/` — یہاں لوگو اور بانی کی تصویر رکھیں

## آگے بڑھانا
یہ ہوم پیج مکمل ماسٹر پلان کے ہر سیکشن (ہمارے بارے میں، ٹیم، خبریں، لائبریری، مصنفین، میگزین، بچوں کا گھر، کورسز، مقابلہ جات، ایونٹس، گیلری، ممبرشپ، رابطہ) پر مشتمل ہے۔ ہر سیکشن کو بعد میں الگ صفحہ (مثلاً `about.html`, `authors.html`) میں تقسیم کیا جا سکتا ہے — چاہیں تو یہ اگلا مرحلہ بھی بنوا لیں۔
